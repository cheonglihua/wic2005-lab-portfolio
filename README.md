# WIC2005 Lab Portfolio

This repository contains my reproducible lab work for WIC2005 Programmable
Networks. Each lab directory includes the explanation, commands, and scripts
needed to run the experiment again.

## Published write-up

The portfolio is also available as a [GitHub Pages site](https://cheonglihua.github.io/ID_REDACTED_wic2005-lab-portfolio/).
The site includes the topology diagram, selected outputs, conclusions, and
links back to this repository.

## Labs

- [Week 1 - Why Programmable Networks Exist](./week-01/README.md)

The Week 1 experiment runs a three-host Mininet topology on an ordinary Linux
bridge. It demonstrates Ethernet learning without a controller or manually
configured forwarding rules.
