Observation: r1 has an alternate forward route via r3, but r2 has no return route to h1. The traceroute reaches r3, then probes time out because h2 replies cannot return to h1.
Static routing does not exchange reachability or recalculate alternate routes. Restoring the physical link restores its connected network but does not re-add the lost static route; a routing protocol such as OSPF could learn and recalculate paths.
